Trust architecture

Private by construction.

AES-256-GCM vault

Authenticated encryption with per-user scrypt-derived keys. Tampered ciphertext refuses to decrypt. KMS envelope path documented for production.

DPDP-aligned

Consent-scoped processing, right to erasure, breach-notification duty and no third-party data sales — India's DPDP Act, 2023 as the baseline.

TLS 1.3 transport

Modern ciphers at the edge, strict security headers, HMAC-integrity sessions, and no-store caching on every API response.

SEBI-clear boundaries

Model outputs are information, not advice — the distinction is printed on every signal, ranking and AI answer, per the IA Regulations, 2013.
